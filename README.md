# BlitzyRepo3_Python
A simple hello world python

## Usage

Print the greeting five times with a for loop, a while loop, or both:

```python
import welcome

welcome.greet_with_for_loop()    # prints "Welcome to Blitzy" 5 times
welcome.greet_with_while_loop()  # prints the same 5 lines using a while loop
```

Run the module directly to call both methods in turn:

```
python3 welcome.py
```

Run the tests:

```
python3 -m unittest discover
```
